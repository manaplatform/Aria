---
name: pdf-report
description: Produce a paginated plain-text Latin-script PDF report from a prepared UTF-8 file.
metadata:
  aria.dependencies: python3
---

Prepare the report source in the workspace using verified evidence. Run the reviewed script with its text input and an output path ending in .pdf under /workspace/outputs. The script uses Helvetica and supports Windows-1252 text. Publish the PDF after validation.
